## The missing twelve bytes have an identified location, not a source solution

Original RAM6032D98 contains `Bg is Zero`, its terminator, and one alignment
byte: 12 bytes. All preceding menu labels through `All Off = Button1` agree in
location and contents. The native draft places `- BG Test -` at 6032D98, while
the original places it at 6032DA4. Every later string, the secret-menu initializer,
the font table and deferred name strings inherit that displacement.

No literal occurrence of the complete RAM address6032D98 was found in the whole
program image. This is not proof that no computed address could reference it.
The prior authenticated CAC8 review establishes that the original error block
CB44-CB68 is unreachable from CAC8: unconditional BRA at CB40 skips it. That
block supplies R12 to the text call; R12 there holds the fade-state address,
not the missing string address. These facts do not uniquely recover the source.

Historical agent_d sources retain a constant-false error block with that
fade-state pointer. The complete-unit preparation explicitly removed it. The
prior CAC8 review warns against reusing that block as an allocator hint or
inventing repeat-slot initialization. No unused string definition or fabricated
constant-false guard was added to fill the twelve-byte gap in this experiment.
A genuine error-check producer or original configuration evidence is still needed.
